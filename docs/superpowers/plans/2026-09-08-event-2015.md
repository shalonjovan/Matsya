> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A self-contained 2015 replay (observed fixture + Dec-1 event sim + comparison chart) that touches no existing flow.

**Architecture:** New `event_2015.py` service (fixture load, event-sim builder, band-agreement metric) + `POST /api/v1/event/2015/replay` and `GET /api/v1/event/2015/compare?simId=` on the existing v1 router + new `Event2015.tsx` view on a separate `#/event/2015` route. Observed and modeled data are never mixed: reference localities carry `source` labels, the metric formula is documented, and no number is hardcoded.

**Tech Stack:** FastAPI + pytest, React + vitest, existing flood pipeline (no physics changes).

**Spec:** Published 2015 anchors — Tambaram 494mm/24h, Chembarambakkam 475mm, Nungambakkam 29cm+, Meenambakkam ~35cm (IMD via Wikipedia/TNM); 29,000 cusecs × 21h Chembarambakkam→Adyar Dec 1–2 (CAG via The Hindu); airport closed till Dec 6, 5,207 flooded roads (ReliefWeb); 400+ deaths, 18 lakh displaced. Hourly shape is a synthetic disaggregation of IMD daily totals (labeled as such, not observed).

- Produces: `compare(sim_id) -> {localities: [{name, reportedBand, modeledMaxCm, modeledBand, match}], recall, bandAgreement, similarityPct, formula, wetThresholdCm}`; `POST /api/v1/event/2015/replay -> {simId, status}` (builds event sim); `GET /api/v1/event/2015/compare?simId= -> envelope`.

Metric (documented in code + UI): modeled band from snapshot max at locality cell: severe ≥100cm, moderate 15–100cm, mild <15cm. `recall` = reported-(severe|moderate) localities with modeled ≥15cm ÷ total. `bandAgreement` = exact band matches ÷ total. `similarityPct = round(50*recall + 50*bandAgreement)`. `wetThresholdCm = 15` param.
