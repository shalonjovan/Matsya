How visualisation works in base Itzi (not web)

  • Inside GRASS: outputs are Space-Time Raster Datasets (STRDS) nc_itzi_tutorial_water_depth_0001..0006 + nc_itzi_tutorial_water_depth_max inside GRASS DB. View with g.gui.animation → select STRDS → Play (see docs/img/nc_itzi_tutorial.png) or d.rast nc_itzi_tutorial_water_depth_0004 + r.colors.
  • Export for external: r.out.gdal input=nc_itzi_tutorial_water_depth_max output=/tmp/nc_depth_max.tif (what we did) → open in QGIS / GDAL. Also t.rast.list to see times 300..1800 s.
  • Stats: nc_itzi_tutorial.csv (volume_error 0.12%→0% after CFL fix).
  • We rendered static PNGs via matplotlib from exported GeoTIFFs for quick view (no GRASS GUI needed). Full animation would be g.gui.animation strds=nc_itzi_tutorial_water_depth exported to mp4 via GUI.
