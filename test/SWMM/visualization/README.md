# MATSYA SWMM Visualization

Interactive live map for Chennai drainage SWMM models.

## Quick Start (Live)

The main viewer `index.html` fetches GeoJSON via `fetch()`, so it **requires an HTTP server** (not `file://`).

```bash
cd test/SWMM/visualization
python -m http.server 8000
# open http://localhost:8000 in browser
# select model via dropdown: Ward N082 (53 drains) or BBox 320 (320 drains)
```

Features:
- **Map**: Leaflet + OSM. Conduits = lines, Junctions = green circles, Outfalls = purple squares. Flooded nodes pulse red, conduits color by capacity (blue→orange→red).
- **Time slider + Play**: 72 periods (00:05–06:00, 5-min steps) animating depth/flow from `.out` binary (`swmm.toolkit.output` `scripts/generate_viz_data.py:30-150`). Updates node depth/flow, system rainfall/runoff/flood, max depth/flow KPIs.
- **System Hydrograph** (Chart.js): Rain (mm/hr), Runoff CMS, Flood CMS, Outfall CMS over time.
- **Detail**: Click any node/conduit → hydrograph of depth + inflow/flow.
- **Legend / KPIs**: Continuity errors, flooded count, total precip 54.167 mm (50 mm/hr×1 hr).

## Standalone (no server)

`matsya_N082_standalone.html` embeds the 1.3 MB JSON for Ward N082 and works via `file://` double-click. No bbox version embedded (7.5 MB would be heavy) — use `index.html`+server for that.

```bash
# just open
xdg-open test/SWMM/visualization/matsya_N082_standalone.html
```

## Static Preview

PNGs for quick view without browser:
- `matsya_N082_map.png` — Ward N082 network, flooded nodes labeled (red)
- `matsya_bbox_320_map.png` — BBox 320 network

Generated by `scripts/generate_static_map.py:1` via matplotlib (conduit colour by max flow, node red if `flood_summary.volume>0`).

## Data Files

Generated by `scripts/generate_viz_data.py:30`:
- `data_matsya_N082.json` — 94 nodes, 54 conduits, 72 periods, 1.3 MB (parsed from `input/matsya_N082.inp`, `output/matsya_N082.rpt/.out`)
- `data_matsya_bbox_320.json` — 552 nodes, 335 conduits, 72 periods, 7.5 MB

Each contains: `center` (lon/lat bounds), `nodes` [{id,lon,lat,elevation,maxDepth,type,flood_summary}], `conduits` [{id,from,to,coords,width,depth,max_flow}], `out_series` {dates, nodes_series{depth,head,flood,inflow}, links_series{flow,depth,velocity,capacity}, sys_series{rainfall,runoff,flood,outfall}}.

## Tips

- If fetch fails (`Failed to load`), ensure you ran `http.server` from this folder and used `http://` not `file://`.
- Use browser devtools Network tab to verify `data_*.json` loads.
- For GIS overlay, `COORDINATES` in `.inp` are WGS84 lon/lat — load `data_*.json` conjoined coords into QGIS as GeoJSON.

## Live Demo Flow

1. Select model
2. Press **Play** — slider animates, map updates, system chart crosshair moves
3. Hover conduits/nodes for tooltip (id, elevation, flood volume)
4. Click for detail hydrograph

Enjoy exploring how 50 mm/hr overloads the small N082 network (13 flooded) vs larger BBox (39 flooded).
